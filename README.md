# 🏛️ StudyHub / CampusOS 98

> A cozy, gamified multiplayer study platform and accessible EdTech workspace styled with a **tactile Retro 90s OS / Y2K Desktop UI** layered over warm, dynamic day-to-night twilight campus backdrops.

---

## 🌟 Key Features

### 1. 🪟 Visual Aesthetic & Retro 90s UI System (`CampusOS 98`)
- **Authentic Retro OS Shell:** Classic 3D beveled borders (`#ffffff` highlights and `#404040` shadows), colorful retro window titlebars, pixel action buttons (`_`, `□`, `✕`), tactile press-down button feedback, and custom retro scrollbars.
- **Dynamic Twilight Campus Canvas Backdrop:** Procedural canvas day-to-night cycle with gothic campus spires, glowing amber library windows, real-time clock tower hands, twinkling starfields, shooting stars, fireflies on the quad, and responsive rain particles.
  - Manual sky switcher: **Golden Hour**, **Twilight**, **Midnight Lo-Fi**, **Dawn**, or **Real-Time**.
- **Interactive Desk Pets:** Tamagotchi Pixel Cat, Rubber Duck Debugger, and Pocket Fire Drake wander your desktop with purrs, quacks, and motivational study reminders.
- **Micro-Interactions & Audio:** Built-in procedural **Web Audio API** synthesizer for UI clicks, 8-bit coin chimes, level-up fanfares, timer bells, and card flips — zero external audio dependencies.

---

### 2. 🗺️ Cozy Virtual Campus & Multiplayer Study Rooms
- **Interactive Quad Directory (`CampusMap.exe`):**
  - Instant keyboard shortcuts:
    - **`L`** — **Quiet Oak Library**: Silent deep focus, warm desk lamps, Adaptive Reader.
    - **`R`** — **Stargazer Rooftop**: Twilight skyline, 50/10 Pomodoro sprint groups.
    - **`C`** — **Bean & Byte Cafe**: Lo-Fi coffeehouse, collaborative study chat, AI Tutor.
    - **`N`** — **Pixel Quad Arcade**: Break-time lounge, 3D Flashcards arena, Campus Shop.
- **Discord-Style Study Servers & Live Tables (`StudyRooms.exe`):**
  - Left server sidebar with `#silent-deep-focus`, `#50-10-pomodoro-sprint`, `#cs-ai-study-group`, and `#lofi-lounge`.
  - Live interactive study tables with animated companion avatars and study task badges.
  - Interactive **"Take This Seat"** feature allowing you to set a custom study status.
  - Shared room Pomodoro synchronization & live collaborative study chat with system notifications.

---

### 3. 🤖 AI Study Assistant & Accessible EdTech
- **AI Study Companion Bot (`StudyBot.exe`):**
  - Retro AIM / MSN Messenger interface with buddy list and chat history.
  - Instant prompt chips: `💡 Explain simply (ELI5)`, `🐞 Debug my code`, `🧠 Quiz me on this`, `📝 Study outline`.
  - One-click **"Export to Flashcards"** button that automatically converts quiz answers into 3D study cards.
- **Adaptive Reader & Smart Notes Summarizer (`Reader.exe`):**
  - Upload notes or select pre-loaded CS, Cognitive Psychology, or Machine Learning lectures.
  - Click **"Summarize & Structure"** to extract key takeaways, structured digests, and glossaries.
  - **Neurodivergent Reading Aids:**
    - **Bionic Reading Mode:** Bolds initial syllables to guide ocular saccades and increase reading fluency.
    - **Dyslexia-Friendly Font:** Enhanced letter spacing and line heights.
    - **Irlen Color Tint Overlays:** Peach, Soft Amber, Mint Green, Lavender, and Ice Blue scotopic tints.
    - **Interactive Focus Ruler:** Draggable reading guide band that blocks visual distractions.
    - **Text-to-Speech (TTS):** Web Speech API reader to listen to notes aloud.
- **3D Active-Recall Flashcards (`Flashcards.exe`):**
  - Realistic 3D card-flip animations.
  - "Got It (+10 XP, +2 Coins)" and "Review Again" buttons.
  - Mastery progress bars, streak tracking, and celebratory confetti upon completing decks.

---

### 4. 🧘 Sensory Focus & Gamified Progression
- **Sound Mixer & Procedural Synthesizer (`SoundMixer.exe`):**
  - Sliders for Pink-Noise Rain, Sub-Bass Thunder, Vinyl Record Crackle, Coffeehouse Murmurs, and 10Hz Alpha Binaural Focus Waves.
- **Sensory CRT TV (`SensoryTV.exe`):**
  - Retro TV widget with scanline overlay and procedural looping visual channels (Lo-Fi rainy window, Minecraft campfire, Mario Kart cyber highway, cozy fireplace).
- **Cinema Focus Mode:**
  - One-click button that dims the entire desktop and non-active windows with a cinematic vignette while illuminating the active study window.
- **Ergonomic Posture Guard (`PostureGuard.exe`):**
  - MediaPipe webcam vision monitor hook with posture alignment score, 20-20-20 eye strain countdown, and quick desk stretches.
- **Gamified Productivity & Campus Shop (`Shop.exe` & `Quests.exe`):**
  - Mechanical dial & digital Pomodoro timer (25/5, 50/10, custom).
  - Daily quest checklist with claimable XP and Campus Coins.
  - Unlockable OS Themes (Classic Windows 95, Vaporwave Neon, Matcha Pastel, Midnight Cyberpunk, Solarized).
  - Unlockable Wallpapers, Desk Pets, and Scholar Badges.
  - Full `localStorage` persistence across refreshes.

## 🚀 Getting Started

### Installation & Development
```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Or build production bundle
npm run build
npm run preview
```

Open [http://localhost:5173](http://localhost:5173) in your browser!
